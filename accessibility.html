Accessibility service prominent disclosure

An unedited screen recording of what Stellar Launcher shows you before its optional double-tap screen lock can be switched on.

  • Optional
  • Off by default
  • Zero data collected

The accessibility service does one thing: it locks the screen when you double-tap the empty home screen, so fingerprint unlock keeps working. It receives no accessibility events, cannot read window content, and reads, collects or shares no personal or sensitive data.
